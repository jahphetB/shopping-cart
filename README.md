# Shopping Cart

https://shopping-cart-phi-six-71.vercel.app/

A responsive mock shopping cart application built with React.

## Features

- Home, Shop, and Cart pages with React Router
- Products fetched from FakeStore API
- Product quantity selection with increment/decrement controls
- Add-to-cart confirmation messages
- Navbar showing the number of distinct cart products
- Cart quantity updates and product removal
- Automatic order total calculations
- Responsive minimalist design with product hover effects
- Component and integration tests using React Testing Library

## Built With

- React
- Vite
- React Router
- JavaScript
- CSS
- FakeStore API
- Vitest
- React Testing Library

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/jahphetB/shopping-cart.git
cd shopping-cart
npm install
```

Start the development server:

```bash
npm run dev
```

Run tests:

```bash
npm run test
```

Create a production build:

```bash
npm run build
```

## Deployment

Deployed on Vercel with SPA routing support.
